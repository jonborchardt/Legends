# unity-animation

## Purpose
Correct animator controller generation and state machine usage. The `AnimatorController` is code-generated — no editor-hand-authored states. All animation calls route through `AthleteAnimator` — never direct `Animator.Play` calls from outside.

## Rules (enforce)
- `AnimatorController` is **generated by script** (`AthleteControllerGenerator.cs`), never hand-edited in the Unity Animator window.
- All external animation calls go through the typed wrapper (`AthleteAnimator`) — no raw `Animator.SetTrigger("foo")` from other classes.
- Animator parameter names are constants, not inline strings.
- State names in the generator and the constant file must stay in sync — the generator is the single source of truth.
- Transitions use `exitTime = false` + condition-driven for responsive state changes.

## Rules (avoid)
- Calling `animator.Play(...)` or `animator.SetTrigger(...)` from outside `AthleteAnimator`.
- Hand-editing `.controller` assets — they are generated artifacts.
- Blend trees for movement unless blending is genuinely needed.
- Sub-state machines unless required by complexity — keep the state graph flat.
- `AnimationEvent` methods on arbitrary MonoBehaviours — route through the animator wrapper.

## Patterns

### Generator pattern
```csharp
// AthleteControllerGenerator.cs (Editor-only)
// Creates the AnimatorController asset programmatically.
var controller = AnimatorController.CreateAnimatorControllerAtPath(OutputPath);

var idle   = controller.AddState("Idle");
var run    = controller.AddState("Run");
var pass   = controller.AddState("Pass");

var toRun  = idle.AddTransition(run);
toRun.AddCondition(AnimatorConditionMode.If, 0, AnimParam.IsRunning);
toRun.hasExitTime = false;
```

### Animator parameter constants
```csharp
public static class AnimParam
{
    public const string IsRunning = "IsRunning";
    public const string Pass      = "Pass";
    public const string Celebrate = "Celebrate";
}
```

### Typed wrapper (AthleteAnimator)
```csharp
public sealed class AthleteAnimator
{
    private readonly Animator _animator;

    public AthleteAnimator(Animator animator) => _animator = animator;

    public void SetRunning(bool value)  => _animator.SetBool(AnimParam.IsRunning, value);
    public void TriggerPass()           => _animator.SetTrigger(AnimParam.Pass);
    public void TriggerCelebrate()      => _animator.SetTrigger(AnimParam.Celebrate);
}
```

### Adding a new state
1. Add constant to `AnimParam`.
2. Add state + transitions in `AthleteControllerGenerator`.
3. Run `Tools > Legends > Build All` to regenerate the controller asset.
4. Add typed method to `AthleteAnimator`.
5. Call the new method from `ReplayDirector` or wherever the trigger fires.

## Anti-patterns
- `athlete.GetComponent<Animator>().SetTrigger("Run")` from `ReplayDirector` — use `AthleteAnimator`.
- Opening the `.controller` asset in the Animator window and adding a state by hand.
- `if (state == "Idle")` — use the `AnimParam` constant.

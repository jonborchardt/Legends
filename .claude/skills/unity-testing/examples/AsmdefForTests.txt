PlayMode test assembly (requires Unity lifecycle — use sparingly):

  Legends.Tests.PlayMode.asmdef
  {
    "name": "Legends.Tests.PlayMode",
    "references": ["Legends.Data", "Legends.Replay"],
    "includePlatforms": [],        ← empty = all platforms
    "optionalUnityReferences": ["TestAssemblies"]
  }

Rules:
- EditMode tests run without entering Play Mode — fast.
- PlayMode tests spin up the Unity runtime — slow; use only when Awake/Start/coroutine is the subject.
- Never reference Legends.UI from a test assembly — UI is not testable without PlayMode,
  and layout is verified by code review, not automated tests.
